# 2. Ответы на вопросы

| Блок | Когда выдан | Папка |
|---|---|---|
| А | в начале хакатона, 5 вопросов | [`block_a/`](block_a/) |
| Б | в середине хакатона, 5 вопросов и вброс | `block_b/` (появится после выдачи) |

Каждый ответ — отдельный SQL-файл к `core`, результат в `results/*.csv`.
Контрольные цифры сверяются автоматически: `make answers` завершается ошибкой,
если хоть одна не сошлась.
