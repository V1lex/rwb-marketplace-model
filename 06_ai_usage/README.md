# 6. Использование ИИ

ИИ-ассистент (Claude Code) — рабочий инструмент команды: помогал писать черновики
SQL, скриптов и текстов. Постановка задачи, выбор архитектуры и проверка результата
остались за нами. Ни одна цифра не попала в сдачу без проверки на данных.

## Что делали сами, что с ИИ

| Часть работы | Как |
|---|---|
| Разбор кейса, требования экспертов, критерии оценки | Сами: расшифровали выступления экспертов, составили диаграмму исходных таблиц |
| Выбор подхода (слои, звезда, правило выручки, ключ покупателя) | Варианты и их сравнение готовил ИИ, утверждали и защищаем мы |
| Профилирование данных, SQL модели и ответов, скрипты сборки | Черновики с ИИ, проверка и правки — наши |
| Концепция дашборда и стратегия | Черновик с ИИ, цифры пересчитаны нами на нашей модели |

## Как проверяли

* **Контрольные цифры — автотест** (`make answers`): проверяются ровно сданные запросы.
  Тест проверили и сам: намеренно испорченная цифра даёт ошибку.
* **39 сверок `raw ↔ core` при каждой сборке**: строки и деньги до копейки.
  Провал откатывает сборку.
* **Ручные выборки** на спорных местах: нормализация городов, отзывы
  на несколько заказов, заказы с несколькими продавцами.

## Где не согласились с ИИ

| Предложение | Почему отказались |
|---|---|
| Отрезать у города хвост с любым кодом штата | Ломает реальный город `sento se` (штат Баия): отрезаем, только если суффикс равен штату строки |
| Хранить даты как `timestamptz` | В источнике нет часового пояса: ночные заказы уехали бы в соседний месяц |
| Опоздание отгрузки считать по заказу | У продавцов одного заказа разные сроки: считаем по единице товара |
| Замеры производительности из черновика стратегии | Сделаны на другой сборке: перемерили на нашей |
