# Профилирование данных

Все цифры получены скриптом [`profiling/profiling.sql`](profiling/profiling.sql)
на загруженной схеме `raw` (550 759 строк). Повторить:
`psql -X -f docs/profiling/profiling.sql`.

Таблица `geolocation` из полной выгрузки Olist в задание не входит
(8 файлов дают ровно 550 759 строк без неё), поэтому в модели её нет.

## Ключи и гранулярность

| Находка | Значение | Решение в модели |
|---|---|---|
| `orders.order_id` уникален | 99 441 / 99 441 | PK `fact_order` |
| `customer_id` против `customer_unique_id` | 99 441 против 96 096 | `customer_id` — снимок адреса на один заказ, человек — `customer_unique_id`. Измерение покупателя строится по `customer_unique_id` |
| `(order_id, order_item_id)` уникален | 112 650 | PK позиции. `order_item_id` — номер единицы: 1.142 единицы на заказ при 1.038 разных товаров. Зерно факта — одна единица товара |
| `(order_id, payment_sequential)` уникален | 103 886 | PK платежа |
| `review_id` не уникален | 98 410 на 99 224 строки | 789 отзывов привязаны к нескольким заказам, у 547 заказов несколько отзывов. Ключ отзыва — `(review_id, order_id)` |
| Формат id | все 32 hex, без пробелов | Натуральные ключи чистые, хранятся как есть |

## Связи и пропуски

| Находка | Значение | Решение |
|---|---|---|
| Заказы без позиций | 775 | Остаются в `fact_order` с флагом `has_items = false`, в выручку не попадают |
| Заказы без платежей | 1 (`delivered`) | Флаг `has_payment = false` |
| Заказы без отзыва | 768 | Ожидаемо, отзыв необязателен |
| Сироты (позиции, платежи, отзывы без заказа; позиции без товара или продавца) | 0 | Всё равно ставим FK: следующая порция данных может их принести |
| Заказы с > 1 продавцом | 1 278 | Выручку продавца считаем только по его позициям, а не по сумме заказа |

## Статусы

| Статус | Заказов | Комментарий |
|---|---|---|
| delivered | 96 478 | Выкуп. Единственный статус, который признаём выручкой |
| shipped | 1 107 | В пути |
| canceled | 625 | У 461 есть позиции, у 6 есть дата вручения |
| unavailable | 609 | Только у 6 есть позиции: товар закончился до сборки |
| invoiced / processing / created / approved | 314 / 301 / 5 / 2 | Промежуточные стадии |

Правило «что считается выручкой» вынесено в справочник статусов (`is_revenue`),
а не размазано по запросам. Аномалии отмечены флагами: 8 `delivered` без даты
вручения и 6 `canceled` с датой вручения.

## Время

| Находка | Значение | Решение |
|---|---|---|
| Диапазон заказов | 2016-09-04 .. 2018-10-17 | Календарь `dim_date` с запасом 2016–2020 |
| Ноябрь 2016 | 0 заказов | Отчёты по месяцам строятся от календаря, иначе месяц пропадает (контроль Q1: 24 строки) |
| После августа 2018 | 20 заказов, ни одного `delivered` | Хвост выгрузки, в выручку не попадают естественным образом |
| Часовой пояс | не указан, местное время Сан-Паулу | Храним `timestamp` без зоны. Перевод в `timestamptz` с серверной зоной UTC сдвинул бы заказы через границу месяца |
| Пустой `order_approved_at` | 160 | NULL, длительность этапа не считаем |
| Передан в доставку раньше оформления | 166 | Флаг `is_chronology_broken`, длительности этапов для таких заказов — NULL |
| Передан в доставку раньше подтверждения оплаты | 1 359 | Нормально для бизнеса: оплата подтверждается позже (boleto), не аномалия |
| Вручён раньше передачи в доставку | 23 | Флаг `is_chronology_broken` |
| `shipping_limit_date` в 2020 году | 4 позиции | Флаг `is_shipping_limit_suspicious`, значение сохраняем |
| Обещанная дата доставки | всегда 00:00 | Тип `date` |

## Деньги

| Находка | Значение | Решение |
|---|---|---|
| `price` | 0.85 .. 6 735, нет нулей | `numeric(12,2)` |
| `freight_value = 0` | 383 позиции | Бесплатная доставка, валидное значение |
| `payment_type` | credit_card, boleto, voucher, debit_card, `not_defined` = 3 | Справочник типов оплаты, `not_defined` — отдельный член |
| `installments = 0` / `payment_value = 0` | 2 / 9 | Флаги на платеже, не удаляем |

| Один товар по разным ценам | 5 900 товаров | Цена — свойство позиции, а не товара. История цен строится из фактов |

## Справочники

| Штатов | продавцов 23, покупателей 27 | Справочник штатов Бразилии с регионами (27 строк) |
